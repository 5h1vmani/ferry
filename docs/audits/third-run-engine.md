## Found safe

- The lock file works as written. `stop` calls `dir_lock.release()` at `engine.rs:1048`, so a second `Engine::new` in the same process takes the lock.
- A lock file that is a directory or unreadable fails at `open` and gives `Runtime::BadConfig` with a plain sentence.
- Nothing outside `DirLock` can close the file handle. The `File` field is private, and `stop` is the only caller of `release`.
- `Engine::drop` calls `stop`, so the pool ring always breaks. No idle connection holds an `Arc<Engine>`, only an `Arc<Shared>`.
- The welcome check cannot be fooled by an address shape. The listener binds an IPv4 socket at `engine.rs:906`, so no IPv4-mapped IPv6 address ever reaches it.
- An unspecified remote address is not loopback, so it is refused while presence is off. That is the safe direction.
- The head cache byte cap holds on every insert. `put` evicts after inserting, so the peak is the limit plus one head.
- The prefetch queue file cap holds. `submit` filters to files and then takes at most 512.
- The prefetch thread is joined by `MountRegistry::stop` and by `stop_all`, on both the waiting path and the between-files path.
- Item 19 paths are safe at the peer. `RemotePath::parse` refuses `..`, and `roots.rs` refuses a root or root-level path for write, truncate, rename, mkdir and delete with `OpError::PermissionDenied`.
- A rename across two roots is refused by the peer with `OpError::Unsupported`.
- A write into a folder is refused with `OpError::IsADirectory`. A write past the end extends the file with zeros, which is the documented core behaviour.
- `write_at` over one mebibyte is refused before the pool is touched, so a refused write never dials.
- No conditional request promise is broken. The bridge never reads `If-Match` or `If-None-Match`, and the lock table matches tokens, not entity tags.
- `put.rs` stats on the wire. Only `file_entry` reads the listing cache, so a landing decision is never made from a cached entry.
- A pool borrow held across `Engine::stop`'s join is harmless. The socket was shut down first, the call fails, the connection is marked unhealthy, and the orphaned pool dies with the caller's own handle.
- `take_dialing` cannot block for ever with no known address. `dial_targets` returns an empty list, so the call fails at once.
- The browse loop drops and restarts its `Browser` correctly. A failed start is retried one tick later.
